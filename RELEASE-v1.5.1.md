# v1.5.1 — practical build packages and review evidence

## Available now

Under Learning path → Packet Tracer practicals → Open build packages, three original text packages provide cables, addressing, per-device configuration downloads, baseline checks, fault injection, repair, fresh tasks and blank execution reports. The routed package also includes an ACL extension and rollback. They target PC-PT, 2960 and 1941 devices; actual installed-device support remains to be checked.

Under Assessment → Exam review workspace, reviewers can export all 100 revised items and record source, device/environment, key/distractor findings and revision requests. Reviews are stored with exact question snapshots and retained through progress backups. Reviewer identity/independence is self-reported. No entry changes the overall unvalidated status. The last 100 review notes are retained; export important work.

The workspace can summarize up to 50 consented attempt exports locally: item correctness, omissions, option selections and conservative exposure counts. It rejects altered item content/keys and duplicate item IDs, recomputes correctness, and skips repeated copies of the same attempt. Counts describe attempts, not unique learners, and do not establish calibration or pass prediction.

Opening a reviewer item records exposure; downloading the full answer pack records all 100 exposures. Answer-revealing review tools cannot open during an unfinished rehearsal.

## Verification and remaining work

Tests cover reviewer export completeness, stale-review rejection, import bounds, score recomputation, corrupt export rejection, duplicate detection, valid address plans and route/policy configuration consistency. These are software/static-content checks, not execution on Cisco devices.

Packet Tracer is not installed on the owner's computer. No `.pkt` files or observed device outputs have been fabricated. Build sheets explain how to save separate baseline, broken and repaired topologies after installing the simulator. Execution status remains pending until real runs are documented.

No external practitioner has reviewed the exam, and no representative learner pilot has run. Item-specific source work is incomplete: IPv4/subnet and ACL references are included as starting points, with other source fields left explicitly pending. New independent assessment forms and full subobjective coverage also remain future work. This release provides tools to collect evidence; it does not erase those limitations.
